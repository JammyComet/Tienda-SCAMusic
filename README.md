# SCAMusica

Tienda musical desarrollada con React 19 y Vite, utilizando
React Router, React-Bootstrap, Bootstrap 5 y LocalStorage.

El proyecto está organizado mediante Atomic Design y utiliza
Context API para gestionar autenticación y carrito.

## Instalación

npm install

## Ejecutar proyecto

npm run dev

## Pruebas unitarias

npm test

Las pruebas utilizan Jasmine, Karma y React Testing Library.
